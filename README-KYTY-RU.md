# Sharpdroid + KytyPS5: сборка только в GitHub Actions

Ничего тяжёлого локально собирать не нужно. Компьютер нужен только чтобы один раз загрузить папку в GitHub.

## 1. Залить проект в свой репозиторий

Через браузер (перетаскиванием) не получится: GitHub принимает не больше 100 файлов за раз, а здесь около 900.
Нужен Git (https://git-scm.com/download/win), он лёгкий и подходит для слабого ноутбука.

1. На github.com создайте **пустой** репозиторий (без README), например `sharpdroid-kyty`.
2. Распакуйте `sharpdroid-kyty.zip`, откройте PowerShell в папке `sharpdroid-kyty` и выполните:

```
git init -b main
git add .
git commit -m "sharpdroid + kytyps5"
git remote add origin https://github.com/ВАШ_ЛОГИН/sharpdroid-kyty.git
git push -u origin main
```

(При запросе входа используйте Personal Access Token с правами `repo` и `workflow`.)

## 2. Запустить сборку

На странице репозитория: **Actions → build → Run workflow**. Её можно запускать и с телефона в браузере.
Галочка *publish* дополнительно создаст GitHub Release с файлами.

Сборка идёт двумя задачами, примерно 1–3 часа в сумме:

1. `payload`: собирает KytyPS5 (linux-x86-64, контейнер Debian 12), получается `kyty-*.zip`;
2. `apk`: собирает host-слой и приложение с уже встроенным Kyty, получается `sharpdroid-kyty.apk`.

## 3. Скачать результат

Внизу страницы выполненного запуска, раздел **Artifacts**: `sharpdroid-kyty` (APK и zip с Kyty)
и `kyty-build` (только zip). APK — отладочный, ставится сразу (разрешите установку из неизвестных источников).

## Если сборка упала

Откройте красный шаг и пришлите мне последние ~50 строк лога. Конвейер ни разу не запускался целиком,
так что первые ошибки вероятны. Особенно в задаче `apk`: скрипты Sharpdroid писались под Windows,
а на Linux-раннере я их не проверял. Кроме того, само приложение на устройстве ещё не проверено (см. `docs/kyty.md`).
